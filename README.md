# Bento-Dots

My personal macOS dotfiles. A Yabai-managed, terminal-centric environment optimized for a hybrid workflow of 3D animation and software development. Built to bring the feel of Hyprland to macOS.
## Features

- yabai: Out-of-the-box tiling logic.
- skhd: Intuitive, easily modifiable keybinds.
- Ghostty: Custom config with cursor trails (via [this repo](https://github.com/sahaj-b/ghostty-cursor-shaders)).
- Oh My Posh: (Slightly) Personalized terminal prompt
